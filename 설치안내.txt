도지봇 웹사이트 업데이트 — 문서함 편집기 / 약관 / 개인정보

1. GitHub Pages에 업로드
ZIP을 풀고 index.html 및 editer-hwp, editer-excel, editer-ppt, terms, privacy 폴더를 현재 웹사이트 index.html이 있는 위치에 올립니다. 폴더 안의 index.html까지 포함하세요. ZIP 자체를 업로드하면 사이트가 변경되지 않습니다.
문서함의 [열기] 옆 [이름 변경]으로 소유자 및 편집자가 문서 이름을 바꿀 수 있습니다. 이름 변경 추가만으로는 SQL을 다시 실행할 필요가 없습니다.
기존 다른 파일은 유지하세요. 배포 후 문서함의 [열기] 또는 문서 제목을 누르면 새 탭에서 해당 편집기가 열립니다.

주소
/editer-hwp/?doc_edit=문서ID
/editer-excel/?doc_edit=문서ID
/editer-ppt/?doc_edit=문서ID
/terms/ — 이용약관
/privacy/ — 개인정보처리방침
/terms 및 /privacy로 들어가도 됩니다. GitHub Pages가 마지막 /를 붙일 수 있으며 .html은 주소에 나오지 않습니다.
기존 /terms.html, /privacy.html은 새 경로로 이동합니다. 새 도메인을 구매할 필요는 없습니다.

2. 저장 기능 설치 (필수)
기존 Supabase 프로젝트의 SQL Editor에서 document_editor.sql 전체를 한 번 실행합니다.
기존 bot_documents 및 bot_document_permissions 테이블을 사용합니다. 기존 문서 행은 유지됩니다.
자동 저장, 수동 저장, 저장 버전 충돌 확인용 함수가 추가됩니다.
SQL을 실행하지 않으면 문서 작성과 다운로드는 가능하지만 서버 저장은 실패합니다.
기존 테이블의 RLS 접근 정책은 그대로 사용하며 별도로 변경하지 않습니다.

4. 사용할 수 있는 기능
텍스트: 글꼴·글자 크기 선택, 글자 서식, 제목, 목록, 링크, 사진 / DOCX·TXT 가져오기 / DOCX 다운로드.
엑셀: 셀 안에서 직접 편집, Shift/드래그 범위 선택, 숫자 자동 채우기, 범위 복사·삭제·서식 변경, 시트 추가·삭제, 행·열 추가, 글자·배경색, 수식 계산 / XLSX·CSV 가져오기 / XLSX 다운로드.
지원 수식: + - * /, 괄호, A1 및 $A$1 참조, SUM·AVERAGE·MIN·MAX·COUNT와 셀 범위.
PPT: 글상자 직접 편집, 텍스트·사진·도형 이동과 크기 조절, 도형 추가, 개체 복제·삭제·앞뒤 순서 변경, 글꼴 선택, 슬라이드 추가·복제·삭제·순서 변경, 제목·본문·메모·색상·사진 / PPTX 가져오기·다운로드.
모든 종류: 자동·수동 저장, 실행 취소·다시 실행, 도지봇 JSON 백업·복구, 인쇄/PDF.
권한: 소유자·편집자는 수정, 보기 권한은 열람. 서버 저장 함수에서도 인증된 Discord 계정과 편집 권한을 검사합니다.
저장 실패 때 기기에 복구본을 남깁니다. 다른 사람이 먼저 저장하면 덮어쓰지 않고 백업 후 다시 열도록 알립니다. 실시간 동시 편집 기능은 아닙니다.

5. 범위 및 제한
이 편집기는 기본 편집 기능을 제공하며 한컴·Microsoft Office 전체 기능을 대체하지 않습니다.
.hwp 및 .hwpx 원본 파일 입출력은 지원하지 않습니다. 텍스트 문서는 한컴에서도 열 수 있는 DOCX를 사용하세요.
DOCX의 복잡한 표·페이지 배치·일부 서식은 보존되지 않을 수 있습니다.
엑셀은 최대 20시트, 각 300행 × 50열입니다. 원본 차트·매크로·복잡한 수식·서식은 유지되지 않습니다. 사이트의 셀 색상과 굵게 서식은 서버/JSON에 저장되지만 XLSX 내보내기에는 반영하지 않습니다.
PPT는 최대 100슬라이드, 각 슬라이드당 최대 100개 개체입니다. 사이트에서 만든 개체의 위치·크기·텍스트·도형·사진은 서버/JSON과 PPTX 다운로드에 반영됩니다. PPTX 가져오기는 제목·본문·첫 사진을 기본 배치로 변환하며 원본 도형·배치·애니메이션·메모를 보존하지 않습니다.
가져올 파일은 10MB 이하, PPT 사진은 PNG/JPG/WebP 2MB 이하입니다.
파일 변환 라이브러리를 불러오는 인터넷 연결이 필요합니다.

약관과 개인정보처리방침은 기존 5개 언어의 본문을 유지하고 디자인만 홈페이지와 맞췄습니다.
다크·화이트·시스템 테마를 제공하고 홈페이지와 선택을 공유합니다. 배경색 설정은 적용하지 않습니다.

검증: JavaScript 구문, 문서 경로, 수식, 저장 실패·충돌, 권한, DOCX/PPTX 생성 및 PPTX 제목·본문 가져오기 검사 완료.
실제 Supabase SQL 실행, GitHub 배포 및 브라우저 화면/Discord 로그인 확인은 이 파일을 업로드한 뒤 진행해야 합니다.

글꼴: 맑은 고딕·굴림·바탕·궁서·Arial·Georgia·고정폭(Consolas)을 선택할 수 있습니다. 설치되지 않은 글꼴은 장치의 대체 글꼴로 표시됩니다. 글꼴 파일을 문서에 포함하지는 않습니다. 한글은 선택한 글자에, PPT는 선택한 텍스트 개체에 적용하고 개체를 선택하지 않으면 슬라이드 전체에 적용합니다. DOCX/PPTX 다운로드에 글꼴 선택을 반영합니다.

이번 업데이트 사용법
[엑셀]
- 셀을 더블클릭하거나 F2를 누르면 셀 안에서 편집합니다. Enter로 저장하고 다음 행, Tab으로 다음 열로 이동합니다. Esc는 입력 취소입니다.
- A1에 1, A2에 2를 입력한 뒤 A1을 클릭하고 Shift+A2 클릭 또는 드래그로 두 셀을 선택하세요.
- 선택 범위 오른쪽 아래 작은 네모를 A10까지 끌면 3~10이 이어서 채워집니다. 가로 방향과 역방향도 지원합니다.
- 또는 A1부터 A10까지 Shift로 선택한 뒤 [연속 채우기 ↓]를 누르세요. 가로 채우기는 [연속 채우기 →]입니다.
- 5, 10처럼 일정한 간격의 수열도 지원합니다. 한 셀만 끌면 값이 반복되고, 연속 채우기 버튼은 숫자 한 개를 1씩 증가시킵니다.
- 텍스트는 반복 복사하고 수식은 상대 참조를 옮깁니다. $A$1 같은 절대 참조는 고정합니다.
- Shift+방향키로 범위를 확장하고 행·열 머리글로 전체 행·열을 선택합니다. Ctrl+A는 전체 시트 선택입니다.
- 선택 범위에 굵게·글자색·배경색을 적용할 수 있습니다. Delete/Backspace는 내용만 지웁니다.
- Ctrl+C / Ctrl+X는 범위의 계산 결과 값을 복사/잘라냅니다. 복사한 수식 자체나 서식까지 붙여넣는 기능은 아직 아닙니다.
- Ctrl+V로 표 데이터를 붙여넣고, 값 하나를 붙여넣으면 선택한 모든 셀에 적용합니다. Ctrl+Z / Ctrl+Y는 실행 취소/다시 실행입니다.
[PPT]
- 텍스트를 더블클릭하거나 선택 후 Enter를 누르면 슬라이드 위에서 바로 입력할 수 있습니다. Esc 또는 다른 곳을 클릭하면 입력을 마칩니다.
- 개체를 클릭하고 끌면 이동합니다. 오른쪽 아래 네모를 끌면 크기를 조절합니다. X/Y/너비/높이 입력도 가능합니다.
- 위의 삽입 도구에서 텍스트 상자·사각형·둥근 사각형·타원·삼각형·선·사진을 추가합니다.
- 선택한 개체를 복제·삭제하거나 맨 앞으로/맨 뒤로 옮길 수 있습니다. 선택한 텍스트의 글꼴·크기·색상·굵게·정렬을 바꿀 수 있습니다.
- 방향키는 개체를 1 단위, Shift+방향키는 10 단위 움직입니다. Delete는 개체 삭제입니다.
- 이전 문서의 제목·본문·사진도 개체로 불러옵니다. 기존 문서를 새로 만들 필요는 없습니다.
- 이 업데이트에 필요한 새 SQL 변경은 없습니다. 이전 document_editor.sql 설치를 마쳤다면 HTML 파일만 덮어쓰세요.
검증 범위: 수열(정수·소수·감소), 수식 참조 복사, 범위 선택·서식·삭제·복사·실행 취소, 개체 이동·크기·서식·직접 입력·복제·삭제·레이어, 실제 PPTX 도형/텍스트/글꼴/위치 생성 검사 완료. 브라우저에서의 실제 마우스 조작 및 배포 후 저장 확인은 별도로 필요합니다.
